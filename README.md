# ✨ Zivara – Jewellery Shopping Website

Welcome to **Zivara**, a stylish jewellery shopping website designed to showcase beautiful jewellery products in an elegant and user-friendly layout.

## 🌟 About the Project

Zivara is a front-end e-commerce website where users can browse jewellery products, search for items, add products to their cart, manage quantities, and explore product management features.

The website uses a luxurious gold, cream, and white color theme to create a premium shopping experience.

## 🚀 Features

- 🛍️ Display jewellery products with images, names, and prices
- 🔍 Search products by name
- 🛒 Add products to the shopping cart
- ➕ Increase or decrease product quantities
- ❌ Remove products from the cart
- 💰 Calculate the grand total
- ➕ Add new products
- ✏️ Update existing products
- 🗑️ Delete products
- 💾 Store cart data using Local Storage
- 📱 Use Bootstrap components and grid layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Browser Local Storage

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Browse the jewellery products and try the search, cart, and product management features.

## 🎯 Project Objective

The main objective of this project is to practice front-end web development by creating an interactive shopping website using HTML, CSS, JavaScript, and Bootstrap.
